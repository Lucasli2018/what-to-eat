# 今天吃啥 · 转盘替你做决定

一个零依赖、单文件的「吃饭选择困难症」终结器。把「今天吃什么」变成一次仪式感转盘——转一下，命运替你拍板，后悔也怪不到自己头上。

## ✨ 特性

- **暖橙系 Canvas 转盘**：屏幕水平排版的菜名（emoji + 菜名上下两行），无倾斜、无重叠、不被中心按钮遮挡；按扇区亮度自动切换深/浅文字色。
- **64 条内置食物库**：覆盖早 / 午 / 茶 / 晚 / 夜宵全时段，一人 / 同事 / 情侣 / 家人 / 朋友多场景。
- **智能筛选 + 分级放宽**：按时段（自动识别当前时间）× 场景 × 预算 × 忌口筛选；候选不足时自动**分级放宽**（时段 → 场景 → 预算），但**忌口永不放宽**。
- **防重复**：`localStorage` 记录近期历史，最近吃过的不会马上再转出来。
- **换一个（限 2 次）**：解决「再想想」本能，用完提示「不能换了，认命吧」。
- **音效 + 震动**：WebAudio 合成旋转滴答声与出结果「叮」声（可静音并记忆偏好）；移动端过扇区短震、出结果长震。
- **自定义食物库**：在「我的食物」里增删个人菜品（菜名 / emoji / 人均 / 辣度 / 标签 / 场景 / 时段），合并进转盘参与全部逻辑。
- **收藏常去**：结果卡一键收藏，收藏的菜抽取时加权（×1.8），越常点越常出。
- **去地图找店**：结果卡一键打开高德地图搜索，无需 API key。
- **深色模式 / 移动端适配**：跟随系统配色，手机上同样好用。

## 🚀 使用

直接双击 `index.html` 即可在浏览器打开，无需任何构建、依赖或服务器。

1. 顶部「调整条件」选择**时段 / 场景 / 预算 / 忌口**；
2. 点中心按钮转转盘；
3. 看结果卡，可「换一个（剩 2 次）」「⭐ 收藏」「📍 去地图找店」；
4. 想加自己的菜：设置面板 → 「我的食物」→「＋ 添加」。

## 📦 部署

纯静态单页，丢到任意静态托管即可（Cloudflare Pages / GitHub Pages / Nginx / OSS…）。以 Cloudflare Pages 为例：连接仓库后构建命令留空、输出目录设为仓库根，即可上线。

## 🔒 数据隐私

所有自定义菜品、收藏、历史、音效偏好都只存在**浏览器本地 `localStorage`**，不上传任何服务器。「🔄 重置」只清场景 / 预算 / 忌口 / 结果，**不会**删除你的自定义食物与收藏。

## 🧱 技术栈

- 纯 HTML + CSS + 原生 JavaScript，单文件零依赖；
- Canvas 绘制转盘，WebAudio 合成音效，Vibration API 震动反馈；
- 无任何外部 CDN、框架或第三方库。
